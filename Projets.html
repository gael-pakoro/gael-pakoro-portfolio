Description :


J'ai fait un programme qui te permet de jouer avec lui au Chifumi. J'ai utilisé Visuel Studio Code pour créer le code et EduPython pour le finaliser.
Il est assez Basic en termes de commandes, j'utilise les commandes IF/ELSE/ELIF, random, INUPUT, la boucle WHILE de nombreuse foix avec bien sûr la commande PRINT(Pas de fonctions)
Et il n'y pas d'interface visuelle stylé, ça n'affiche que les réponses et les consignes dans la console du logiciel.
En ce momment, j'apprend avec des vidéos Youtube à faire un jeux vidéo. J'ai pas de thème précis pour un futur projet mais je teste beaucoup de chose intéressante avec ces vidéos.
